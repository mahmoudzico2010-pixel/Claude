# Rich "glass" product page (separate update)
Install: unzip over the site root (no migration, no npm build — the styles are inline in the page), then `php artisan optimize:clear`. Works on top of the corrected catalogue release.

What the page now has: elegant glass layout (translucent blurred panels over a soft green/gold gradient; solid fallback where blur is unsupported or "reduce transparency" is on); header panel with category, title, summary, key-fact chips (cultivar, cut, colour, processing), Request-a-quote / spec-sheet / packaging-options buttons and other-cut pills with thumbnails; Overview; Specifications; **Packaging options with previews**; nutrition and certifications when present; a quote band; related products. The existing gallery, zoom, lightbox and optional photo frame are unchanged.
Packaging (updated): each card now uses the REAL photograph of the approved packaging-catalogue pack behind that pack type (found through the legacy-type mapping, or the pack's own link), and a weights table sits directly under the photo with BOTH drained weights — Whole and Pitted/sliced — plus net, gross (when stored) and units per carton. A missing value reads "On request" (translated). A pack type with no approved catalogue pack keeps its own stored values and the schematic illustration. The photo and weights come from the Packaging catalogue (Catalogue → Packaging Catalog); edit them there. Packs linked to the product (Products → edit → packaging, or Bulk edit → Packaging) are shown first, badged "Available for this product", with their capacity/weights/units per carton. If none is linked, the general formats we offer are shown with a note to confirm in the quote — no compatibility is claimed. Preview = the pack photo if one is uploaded, otherwise a schematic illustration by pack type (labelled as an illustration).
Languages: all 18 new texts exist in ar, en, es, fr, it, pt, el, ru, zh, ur (`lang/*/pdp.php`, registered in the interface-text list; Arabic/Urdu render right-to-left). Product copy, specifications, cut/colour/processing labels already come from the 10-language data.
Tests: ProductPageRichTest (181 assertions, incl. catalogue photo + both drained weights in all 10 languages: all 10 locales), CatalogStorefrontTest (590 pages), InterfaceTextsTest — pass. Screenshots: English desktop, Arabic desktop/mobile, Urdu mobile.
Not done / be aware: the demo packaging has no photographs (illustrations shown); the facts shown in the chips are only what is stored; the page was checked in Chromium, not on Safari or real phones; MySQL 5.7 NOT RUN.
