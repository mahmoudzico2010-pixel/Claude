# Google Search Console — short guide (after the release is live)

1. **Property.** Add a *Domain* property for `wadielrayan.net` (covers http/https/www/non-www) or a *URL-prefix* property for `https://wadielrayan.net/`. Verify with the DNS TXT record Google shows (Domain) or the HTML-tag method (URL-prefix).
2. **Submit the sitemap.** *Indexing → Sitemaps* → enter `sitemap.xml` → Submit. Status should become **Success**; "Discovered URLs" should be roughly the number of `<loc>` entries (one per genuine language version). A sitemap is a discovery aid, not a guarantee of indexing.
3. **Inspect representative URLs** (*URL Inspection* at the top): the homepage `/en` and `/ar`, one category, one product (`/en/products/…` and its `/ar/…` twin), the Private Label page and a packaging page. For each check: *Page is indexable*, **User-declared canonical = Google-selected canonical** (`https://wadielrayan.net/…`), and *Rendered HTML* shows the product image and the single `<h1>` on the homepage. Use **Request indexing** only for a handful of key pages.
4. **www / http.** Inspect `https://www.wadielrayan.net/en` — it must report a redirect (301) to `https://wadielrayan.net/en`.
5. **International targeting.** There is no setting to configure: hreflang is in the page head and the sitemap. If *Pages → Alternate page with proper canonical tag* appears for a language, the page is a fallback copy of the default language (by design, it points at the default).
6. **Watch for 1–4 weeks:** *Indexing → Pages* (duplicates "Duplicate without user-selected canonical" should fall; "Alternate page with proper canonical" for www is expected), *Sitemaps*, *Enhancements → Breadcrumbs / Products*. Product rich results are **not expected**: this is a request-a-quote catalogue with no price, rating or stock, so Google may report Product items as "merchant listing not eligible" — that is correct and nothing was invented to change it.
7. Do **not** use the Removals tool for www; the redirect does the job.
